# webstore_temp
Проект в рамках дисциплины ОТРПО

Для организации работы необходимо установить Node.js и npm версии не ниже 22.0.0
Для инициализации проекта необходимо выполнить команду npm init -y
Для установки необходимых пакетов необходимо выполнить команду npm install react-native

После выполнения у вас появятся:
 - папка node_modules (содержит все зависимости проекта)
 - файл package-lock.json (содержит информацию о зависимостях проекта)
 - файл package.json (содержит информацию о проекте)
